# Omi Project Overview

## Project Purpose
Omi is the world's leading open-source AI wearable device that captures conversations, provides summaries, action items, and performs actions for users. It's a comprehensive ecosystem consisting of:

- **Omi Device**: AI wearable hardware with audio capture capabilities
- **Omi Glass**: Smart glass variant of the device
- **Omi App**: Flutter-based mobile companion application
- **Backend**: Python FastAPI server for AI processing
- **Web Platform**: AI personas and web interface

## Key Features
- Real-time AI audio processing
- 24+ hour battery life on a button battery
- Low-powered Bluetooth connectivity
- Open-source software stack
- Wearable ergonomic design
- Automatic conversation transcription and summarization

## Repository Structure
- `omi/`: Hardware device firmware (C++/Zephyr RTOS)
- `omiGlass/`: Smart glass device firmware
- `app/`: Mobile application (Flutter/Dart)
- `backend/`: AI processing server (Python/FastAPI)
- `web/`: Web platform and AI personas
- `docs/`: Documentation (Mintlify)
- `sdks/`: Software development kits
- `scripts/`: Build and utility scripts
